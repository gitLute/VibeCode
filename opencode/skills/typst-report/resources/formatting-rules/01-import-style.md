# Импорт и стиль (преамбула)

Блок: начало файла отчёта, подключение пакета Ghost и применение ГОСТ-стиля.

## Синтаксис

```typ
#import "@mih4n/ghost:1.0.1": *
#show: styles.extended
```

## Проверка окружения (обязательна)

Перед любой работой с отчётом прогони `resources/env-check.typ` и `typst --version`
(см. «Обязательная проверка окружения» в `SKILL.md`): скомпилированный пакет
Ghost бывает сломан, и без проверки это выясняется только при компиляции
готового отчёта.

## Известные правки пакета Ghost 1.0.1

Пакет устанавливается из репозитория `gitLute/GhostExtended`, но после
обновления (`typst update`) требует двух локальных правок — иначе не работает
**ни один** импорт пакета:

1. `pages/index.typ` и `styles/index.typ` ссылаются на удалённые локальные
   файлы `pages/diploma-title.typ` и `styles/diploma.typ`. Строки импорта
   `#import "diploma-title.typ" as diploma-title` и
   `#import "diploma.typ": diploma`, а также ключи `"diploma-title"` и
   `"diploma"` в словарях `pages`/`styles` нужно удалить.
2. В `pages/curse-title.typ` из сигнатуры `#let page(...)` пропал параметр
   `course`, хотя тело функции использует `#course` (строка «по дисциплине»).
   Параметр нужно вернуть: `course: "ооп"`.

При изменении файлов пакета делай бекап (суффикс `.bak-before-fix`).
Проверить результат — `resources/env-check.typ`.

## Правила

1. Импортируются **все** функции пакета Ghost через `: *`.
2. Применяется стиль `styles.extended` — наиболее полная к ГОСТ реализация пакета
   Ghost.
3. Фиксов в файле отчёта стиль не требует: всё, что даёт `styles.extended`,
   реализовано внутри пакета.

## Что даёт `styles.extended` (реализовано в стиле)

1. Разделы (уровень 1) — с нового листа, ПРОПИСНЫМИ полужирными.
2. Подразделы (уровень 2) — полужирные строчными с первой прописной.
3. Пункты (уровень 3) — без заголовков, нумеруются как обычные абзацы.
4. Приложения — автоматическая нумерация буквой через блок `#appendix`.
5. Структурные части («ВВЕДЕНИЕ», «ЗАКЛЮЧЕНИЕ» и т. п.) — по центру, с нового листа,
   если бы использовались; в лабораторной работе не используются.
6. Нумерация страниц — по умолчанию включена (арабская цифра в правом нижнем углу,
   кегль 12pt); в лабораторной работе не требуется и отключается `#page-num-off()`
   (см. `13-page-numbers.md`).
7. Нумерация рисунков и таблиц — сквозная («Рисунок 1», «Таблица 1»), так как
   в лабораторной работе нет заголовков-разделов; в приложениях — по букве
   («Рисунок А.1», «Таблица Б.1»).

## Принципы работы стиля (под капотом, из кода extended.typ)

### Базовые установки (задаёт стиль — в отчёте НЕ повторять)

```typ
set text(font: "Times New Roman", size: 14pt, lang: "ru", hyphenate: false)
set page(paper: "a4", margin: (left: 3cm, right: 1cm, top: 2cm, bottom: 2cm))
set par(justify: true, spacing: 0.5em, leading: 0.5em, first-line-indent: (amount: 1.25cm, all: true))
set list(indent: 1.25cm)
set enum(full: true, numbering: "1.1.")
set heading(numbering: "1.1.1")
```

Значение для автора отчёта:

- Поля страницы: **левое 3 см, правое 1 см, верхнее 2 см, нижнее 2 см** (A4).
- Текст — Times New Roman **14pt**, **выравнивание по ширине**, межстрочный интервал и
  интервал между абзацами — **0.5em**, **абзацный отступ 1.25 см** у ВСЕХ абзацев
  (в т.ч. первой строки).
- **Переносы слов отключены** (`hyphenate: false`) — и в основном тексте, и в заголовках.
- Нумерация заголовков — «1», «1.1», «1.1.1» **без точек в конце**; перечислений —
  сквозная вложенная «1.», «1.1.».

### Регистры наименований (`fix-case`, `structural-case`)

- `fix-case` (заголовки, записи содержания, маркеры приложений): строчными с первой
  прописной; **одиночные буквы** (обозначения приложений «А», «Б») не изменяются;
  **сплошные ПРОПИСНЫЕ слова** приводятся к строчным; двойные пробелы сохраняются.
- `structural-case` (структурные части уровня 1 с `numbering: none`): «введение»,
  «заключение», «содержание» — **ПРОПИСНЫМИ**; остальные («реферат», «перечень условных
  обозначений и сокращений», «список использованных источников») — `fix-case`.

### Латиница

Все латинские буквы в документе автоматически становятся **курсивом**
(`show regex("[a-zA-Z]"): set text(style: "italic")`) — включая подписи рисунков,
таблиц, формулы и обычный текст. Вручную курсив для латиницы НЕ ставится.

## Примечание про лабораторную работу

В лабораторной работе заголовки разделов заменены выделенным текстом (`*...*`),
поэтому уровни 1-3 заголовков в тексте не используются — нумерация рисунков
и таблиц остаётся сквозной автоматически.

## Запреты

- Не использовать альтернативные пакеты для оформления по ГОСТ — только Ghost.
- Не добавлять в отчёт «фиксы» под стиль (пробельные строки после заголовков
  уровней 1-2, ручную нумерацию и т. п.) — стиль это делает сам.
