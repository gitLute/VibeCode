# Титульный лист

Блок: первая страница отчёта. Формируется функцией пакета Ghost с параметрами
работы, студента и руководителя. Два варианта: для лабораторной работы —
`pages.title`, для пояснительной записки — `pages.curse-title`.

## Синтаксис — лабораторная

```typ
#page-num-off() // В лабораторной нумерации нет
#(pages.title)(
  number: 1, // Номер лабораторной работы.
  course: "Программная инженерия", // Название дисциплины
  theme: "Разработка алгоритмов обработки данных", // Тема работы
  group: "ИТИ-31", // Академическая группа
  student: "Фамилия И.О.", // Исполнитель
  supervisor: "Фамилия И.О.", // Научный руководитель
  supervisorTitle: "доцент", // Должность руководителя
  year: 2026 // Год защиты
)
```

## Синтаксис — пояснительная записка

```typ
#no-page-num-start()
#(pages.curse-title)(
  speciality: "Информационные системы и технологии",
  specialityCode: "6-05-0611-01",
  course: "Объектно-ориентированное программирование",
  documentType: "курсовой",
  theme: "Проектирование информационной системы управления заказами предприятия",
  group: "ИТП-41",
  student: "Фамилия И.О.",
  supervisor: "Фамилия И.О.",
  supervisorTitle: "доцент",
  year: 2026
)
#no-page-num-end()
```

Параметры: `speciality`, `specialityCode`, `course`, `documentType`, `theme`,
`group`, `student`, `supervisor`, `supervisorTitle`, `year`. Значение
`documentType` подставляется в строку «к <documentType> работе»
(например, `documentType: "курсовой"` — «к курсовой работе»). Номер страницы
подавляется так же, как в лабораторном варианте.

## Правила

1. Титульный лист — **первый блок** файла после преамбулы (импорта и стиля).
2. Обязательные параметры: `number`, `course`, `theme`, `group`, `student`,
   `supervisor`, `supervisorTitle`, `year`.
   - `student` и `supervisor` — в формате «Фамилия И.О.».
   - `year` — год защиты (число без кавычек).
3. В лабораторной работе нумерация страниц **не требуется**: номера не ставятся
   ни на одной странице документа. Перед титулом достаточно поставить
   `#page-num-off()` (в конце `pages.title` сам ставит разрыв страницы); пара
   `#no-page-num-start()` / `#no-page-num-end()` в лабораторной работе
   не используется (подробнее — `13-page-numbers.md`).
4. В ПЗ номер страницы на титульном листе **не ставится**:
   `#no-page-num-start()` ставится **перед** титулом, `#no-page-num-end()` —
   **сразу после** него. Подавляется номер ровно на странице, где стоит `start`.
   Порядок «start → титул → end» менять нельзя: без `end` номер будет подавлен
   и на следующих страницах.

## Как устроен pages.title (из пакета Ghost, pages/title.typ)

- Функция `pages.title` из пакета **не зависит от `styles.extended`** и формирует
  титул полностью сама: шапка (МИНИСТЕРСТВО..., вуз, факультет, кафедра), затем
  «ЛАБОРАТОРНАЯ РАБОТА №N», «по дисциплине», «на тему», блок «Выполнил/Принял»
  (слева, отступ 9.5 см), внизу по центру «Гомель <год>».
- Параметр `number` — номер лабораторной работы (подставляется в «ЛАБОРАТОРНАЯ
  РАБОТА №N»).
- В конце функция сама ставит `pagebreak()` — титульный лист занимает ровно одну
  страницу, следующий блок начинается со страницы 2.
- Титул печатается 14pt; межблочные интервалы заданы внутри функции — в отчёте
  ничего дописывать не нужно.

## Запреты

- Не выдумывать структуру титульного листа — только `pages.title` (лабораторная)
  или `pages.curse-title` (ПЗ) с параметрами выше.
- Не путать титулы: в лабораторной работе — `pages.title` (параметры `number`,
  `course`), в ПЗ — `pages.curse-title` (параметры `speciality`,
  `specialityCode`, `documentType`).
- Не ставить титульный лист не первым блоком и не писать под ним других блоков
  до конца блока управления нумерацией (`#page-num-off()` в лабораторной работе,
  `#no-page-num-end()` в ПЗ).
