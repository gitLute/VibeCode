# Таблицы

Блок: таблица со сквозной нумерацией в тексте и с нумерацией по букве
приложения в приложениях. Единая функция `#table-block` из пакета Ghost.

## Синтаксис — таблица в тексте

```typ
\
#table-block(
  title: "Исходные данные",
  columns: 3,
  align: (center, center, center),
  header: ([Имя файла], [Время исследования, с], [Количество точек]),
  rows: (
    ([z1.csv], [30], [1000]),
    ([z2.csv], [45], [500]),
  ),
)
\
```

## Синтаксис — таблица в приложении

Буква приложения определяется **автоматически** (функция `#appendix` публикует
её в `state("appendix")`), поэтому `part` передавать не нужно:

```typ
\
#table-block(
  title: "Тестовые массивы",
  columns: 2,
  align: (left, left),
  header: ([Номер теста], [Массив данных]),
  rows: (
    ([1], [[10, 7, 8, 9, 1, 5]]),
    ([2], [[3, 0, 7, 1, 5, 2]]),
  ),
)
\
```

## Секционная нумерация в ПЗ

В пояснительной записке таблицы нумеруются
**в пределах раздела**: «Таблица 2.1» (номер раздела + порядковый номер). Это
происходит автоматически, когда в документе есть заголовки разделов уровня 1
(счётчики `sec`/`tab` сбрасываются при каждом разделе). Ссылка в тексте:
«... по таблице 2.1». Синтаксис блока при этом тот же, `part` не передаётся.

## Правила

1. Название «Таблица N -- Название» формируется **автоматически** со сквозной
   нумерацией (нет заголовков-разделов → «Таблица 1», «Таблица 2»).
2. Название таблицы, при его наличии, должно отражать её содержимое, быть
   **точным и кратким**.
3. Каждую таблицу в зависимости от её размера рекомендуется помещать
   **непосредственно за абзацем, в котором впервые дана на неё ссылка**, либо на
   следующей странице. При необходимости допускается оформлять таблицу в виде
   приложения к отчёту.
4. Таблицы, за исключением таблиц приложений, нумеруются **арабскими цифрами
   сквозной нумерацией**.
5. **На все таблицы должны быть приведены ссылки в тексте**: «... по таблице 1».
6. **Пробельные строки обязательны до и после таблицы**.
7. `header` — массив ячеек шапки (строка шапки автоматически полужирная),
   `rows` — массив массивов ячеек.
8. Параметры `columns` и `align` задают число столбцов и выравнивание ячеек.

### В приложениях

9. Таблицы каждого приложения обозначают **отдельной нумерацией арабскими
   цифрами** с добавлением перед цифрой обозначения приложения: «Таблица Б.1».
10. Буква приложения определяется **автоматически**: `#appendix` публикует её
    в `state("appendix")`, и `#table-block` в приложении сам формирует подпись
    «Таблица Б.1» — параметр `part` передавать не нужно (он остаётся только
    как явное переопределение).
11. Если в приложении одна таблица — она обозначается «Таблица Б.1».

## Как работает #table-block (из blocks/tables.typ и extended.typ)

- Подпись «Таблица N -- Название» формирует сама функция: в пределах раздела —
  «Таблица 4.2» (номер раздела + порядковый номер, счётчики `sec`/`tab`), без
  разделов — сквозная «Таблица 1», в приложении — «Таблица Б.1» (счётчик `tab-Б`).
- Буква приложения берётся из `state("appendix")`, которую публикует `#appendix`
  (см. `12-appendix.md`): в приложении `part` можно не указывать — буква
  подставляется автоматически.
- Сброс счётчиков: при заголовке раздела уровня 1 (в `styles.extended`) и при
  `#appendix` (для счётчика приложения). Вручную сбрасывать ничего не нужно.
- Параметры по умолчанию: `columns: auto` (число колонок — по шапке `header.len()`
  или по первой строке `rows`), `stroke: 0.5pt`, `inset: 5pt`, `align: auto`.
- Текст в таблицах — **12pt** (`show table: set text(size: 12pt)`).
- Шапка (строка `y: 0`) — **полужирная автоматически**
  (`show table.cell.where(y: 0): strong`), вручную жирность в шапке не ставится.
- Таблицы **остаются разрывными** между страницами (в отличие от рисунков).

## Запреты

- Не нумеровать таблицы вручную в названии.
- Не забывать ссылку на таблицу в тексте.
- Не пропускать пробельные строки перед и после таблицы.
