# Выделенные блоки (Цель работы, Задание, разделы, Вывод)

Блоки: «Цель работы», «Задание», заголовки разделов, «Вывод». В лабораторной
работе оформляются **выделенным текстом** (`*...*`), а не заголовками-уровнями
Typst. **Ветка ПЗ использует настоящие заголовки-уровни — см. `14-pz.md`.**

## Синтаксис

```typ
*Цель работы:* изучить типовые алгоритмы обработки одномерных массивов, ...

\
// пробельная строка

*Задание:*
+ Изучить типовые алгоритмы обработки одномерных массивов;
+ Разработать алгоритмы, программы и тесты ...;
+ Сравнить производительность различных алгоритмов сортировки.

\

*Теоретические сведения*

\   // пробельная строка после выделенного заголовка раздела

...текст раздела...

\

*Вывод:* в результате выполнения лабораторной работы изучены ...

\
```

## Правила

1. Названия блоков — **выделенный текст** `*Текст:*`, без номеров и без
   заголовков-уровней. Двоеточие — внутри выделения: `*Цель работы:*`.
2. «Цель работы» — один абзац после `*Цель работы:*`.
3. «Задание» — вводная строка `*Задание:*`, затем нумерованный список `+`
   (допускается таблица вместо списка).
4. Разделы — `*Название раздела*` на отдельной строке (например,
   «Теоретические сведения», «Ход выполнения работы»), после него **пробельная
   строка**, затем текст.
5. «Вывод» — блок `*Вывод:*` + один абзац с итогами, в конце — пробельная строка.
6. Пробельные строки обязательны между этими блоками и соседними элементами.
7. Поскольку заголовков-разделов нет, стиль даёт сквозную нумерацию рисунков
   и таблиц («Рисунок 1», «Таблица 1») — ничего вручную нумеровать не нужно.

## Роль структурных частей

В лабораторной работе структурные части «Введение / Заключение / Список
источников» не обязательны — их роль выполняют выделенные блоки «Цель работы»,
«Задание» и «Вывод».

## Принципы стиля, влияющие на выделенные блоки

- `*...*` — это обычное полужирное выделение Typst; стиль `styles.extended` его
  не переопределяет, поэтому так оформленные блоки печатаются полужирным шрифтом 14pt.
- Латиница внутри выделенных блоков (например «ARIMA») автоматически курсивом.
- Выделенные блоки не являются заголовками-уровнями, поэтому НЕ получают
  автоматической пробельной строки из стиля — пробельную строку после них ставят
  вручную (`\`).

## Запреты

- Не использовать `#heading` уровней 1-3 для этих блоков в лабораторной работе.
- Не ставить пробельную строку ВНУТРИ «Цель работы» — это один абзац.
