# Пояснительная записка (ПЗ)

Блок: отдельная ветка оформления — пояснительная записка (ПЗ).
Эталон: каталог `resources/curse-style/`. Стиль — тот же `styles.extended`,
титульный лист — `pages.curse-title`.

**Когда применять:** запрос про ПЗ, пояснительную записку, записку к курсовой
или дипломной работе.
**Когда НЕ применять:** лабораторная/курсовая/расчётная работа.

## Обязательная структура ПЗ

```
СОДЕРЖАНИЕ -> ВВЕДЕНИЕ -> разделы (подразделы, пункты) ->
ЗАКЛЮЧЕНИЕ -> Список использованных источников -> приложения.
```

Разделы начинаются с нового листа; заголовок и текст разделяются пробельной
строкой (автоматически).

## Титульный лист ПЗ

Отличается от лабораторного титула: вместо `number`/`course` — специальность.

```typ
#no-page-num-start()
#(pages.curse-title)(
  speciality: "Информационные системы и технологии",
  specialityCode: "6-05-0611-01",
  course: "Объектно-ориентированное программирование",
  documentType: "курсовой",
  theme: "Проектирование информационной системы управления заказами предприятия",
  group: "ИТП-41",
  student: "Фамилия И.О.",
  supervisor: "Фамилия И.О.",
  supervisorTitle: "доцент",
  year: 2026
)
#no-page-num-end()
```

Параметры: `speciality`, `specialityCode`, `course`, `documentType`, `theme`,
`group`, `student`, `supervisor`, `supervisorTitle`, `year`. Параметр
`documentType` задаёт вид работы в строке «к <documentType> работе»
(`"курсовой"` — «к курсовой работе», `"дипломной"` — «к дипломной работе»).
Номер на титуле — под `#no-page-num-start()`.

## Содержание

Формируется автоматически из заголовков документа — `#outline`. Заголовок
«СОДЕРЖАНИЕ» выравнивается по центру самим стилем. Пункты (уровень 3) в содержание
не попадают.

```typ
#no-page-num-start()
#outline(title: [*СОДЕРЖАНИЕ*])
#no-page-num-end()
```

Номер страницы подавляется на ПЕРВОЙ странице содержания: если содержание растянется
на несколько страниц, номер появится на всех, кроме первой.

## Заголовки: разделы, подразделы, пункты

В ПЗ используются НАСТОЯЩИЕ заголовки-уровни (в отличие от лабораторной работы):

| Уровень | Синтаксис | Оформление стилем |
|---|---|---|
| Раздел | `= Название` | С нового листа, ПРОПИСНЫМИ полужирными, с абзацного отступа 1.25 см |
| Подраздел | `== Название` | Полужирный, строчными с прописной, абзацный отступ 1.25 см |
| Пункт | `=== Текст пункта` | Как обычный абзац: номер курсивом в начале, текст обычным, после номера отступ |

### Правила уровней

1. **Писать текст напрямую в разделе запрещено** — только подразделы. Вводный
   (не входящий в подразделы) текст раздела размещается непосредственно после
   заголовка раздела ДО первого подраздела (требование 18).
2. Пробельная строка после заголовка раздела/подраздела ставится АВТОМАТИЧЕСКИ
   стилем — вручную НЕ добавляется.
3. Пробельная строка ПЕРЕД подразделом ставится вручную, ТОЛЬКО когда слева от
   заголовка обычный текст (см. `03-blank-lines.md`).
4. Пункт — часть текста: пробельную строку после пункта НЕ ставят, пункты не
   попадают в содержание.
5. **В одном подразделе должно быть не менее двух пунктов**; единственный
   (одиночный) пункт нумеровать НЕЛЬЗЯ (требование 9) — его текст излагают без
   нумерации пункта.
6. Заголовок подраздела нельзя оставлять в конце листа (стиль держит его через
   `block(breakable: false)`); последнюю строку текста нельзя переносить одну
   на новый лист (widow/orphan) — при вёрстке следить за разрывами абзацев.
7. Многострочные заголовки выравниваются по первой букве первой строки,
   переносы в заголовках запрещены.

## Структурные части (Введение, Заключение, Список источников)

Оформляются `#heading(level: 1, numbering: none)` — стиль печатает их по центру
полужирными с нового листа и добавляет в содержание строчными с первой прописной:

- «Введение», «Заключение» — в целом виде ПРОПИСНЫМИ в макете;
- «Список использованных источников» — строчными с первой прописной в макете.

```typ
#heading(level: 1, numbering: none)[Введение]
#heading(level: 1, numbering: none)[Заключение]
#heading(level: 1, numbering: none)[Список использованных источников]
```

После структурных частей пробельная строка ставится стилем автоматически
(они — заголовки уровня 1).

## Список использованных источников

- Записи списка — обычные абзацы, нумерация задаётся вручную текстом («1.»,
  «2.»), выравнивание — по ширине.
- Формат записи: «Авторы. Название. -- издание. -- Город: Издательство,
  год. -- число с.». Тире внутри записей — `--`.
- Ссылки на источники в тексте — в квадратных скобках: `[1]`.
- Пробельная строка между заголовком и списком ставится стилем автоматически
  (заголовок уровня 1); между записями списка — пробельные строки.

## Таблицы и рисунки в ПЗ

Нумерация — В ПРЕДЕЛАХ РАЗДЕЛА (по ГОСТ 7.32): «Таблица 2.1», «Рисунок 2.1»
(номер раздела + порядковый номер). Счётчики сбрасываются при каждом заголовке
раздела автоматически. Ссылки в тексте: «... по таблице 2.1», «... на рисунке 2.1».
Синтаксис `#table-block` / `#picture` — как в файлах `08-tables.md` и
`09-figures.md` (без `part`, если объект вне приложения).

## Требования к тексту ПЗ (дополнительно к `04-text-language.md`)

1. Каждый абзац раздела, подраздела и пункта должен состоять **не менее чем из
   двух предложений** (требование 8).
2. В подразделе не должно быть единственного (одиночного) пункта (требование 9) —
   см. выше п. 5.
3. Текст, не входящий в подразделы, — сразу после заголовка раздела до первого
   подраздела (требование 18).
4. Головные слова обязательных требований: «должен», «следует», «необходимо»,
   «требуется, чтобы», «не допускается», «запрещается»; для остального —
   повествовательная форма («допускают», «указывают», «применяют»).
5. Тире `--` / дефис `-`; длинное тире (`---`, знак «—») строго запрещено.

Остальные общие правила (экранирование, тильда, пробельные строки, листинги,
приложения) — общие для обоих эталонов: см. `05`, `03`, `10`, `12`.
Нумерация страниц для ПЗ (обязательна, титул без номера) — см. `13-page-numbers.md`
(в лабораторной работе нумерация страниц не требуется).

## Запреты

- Не использовать титул `pages.title` в ПЗ (только `pages.curse-title`).
- Не пропускать `#outline` — структура ПЗ обязательна (СОДЕРЖАНИЕ первый).
- Не нумеровать одиночный пункт в подразделе.
- Не писать текст непосредственно в разделе уровня 1 (только подразделы/пункты).
- Не ставить вручную пробельную строку после заголовков разделов/подразделов.
- Не переделывать ПЗ в лабораторную работу и наоборот без явной просьбы.
