# Нумерация страниц

Блок: управление нумерацией страниц отчёта. Обеспечивается стилем `styles.extended`
и управляется командами пакета.

## Лабораторная работа (отчёт) — нумерация НЕ требуется

По ГОСТ в лабораторных и расчётных работах номера страниц **не ставятся**:
ни на титульном листе, ни на остальных страницах документа.

Достаточно выключить нумерацию в начале файла, перед титульным листом:

```typ
#page-num-off()
#(pages.title)(...)
```

Нумерация остаётся выключенной на всём документе — больше ничего делать
не нужно. Пара `#no-page-num-start()` / `#no-page-num-end()` в лабораторной
работе **не используется** (она нужна только в ПЗ).

## Пояснительная записка (ПЗ) — нумерация обязательна

В ПЗ нумерация **включена по умолчанию**: номер —
арабская цифра в **правом нижнем углу**, кегль **12pt**, физический счёт страниц
(титульный лист = 1). Титульный лист — **без номера**: перед титулом ставится
`#no-page-num-start()`, сразу после — `#no-page-num-end()`; дальше номера
печатаются автоматически.

## Команды управления

| Команда | Действие |
|---|---|
| `#page-num-on()` | включить нумерацию страниц |
| `#page-num-off()` | выключить нумерацию страниц (весь документ; используется в лабораторной работе) |
| `#page-num-offset(n)` | смещение исчисления: с места вызова нумерация увеличивается на `n` (n может быть отрицательным) |
| `#no-page-num-start()` | НЕ показывать номер на странице, где стоит `start` |
| `#no-page-num-end()` | закрыть блок подавления (сам номер не подавляет) |

## Правила (для ПЗ и включённой нумерации)

1. `#no-page-num-start()` ... `#no-page-num-end()` — подавляет номер ровно на
   странице, где стоит `start`. По ГОСТ так прячут номер на титульном листе ПЗ.
2. `#page-num-offset(n)`:
   - **несколько вызовов суммируются** (например, рецензия `+1` и вкладка `+3`
     дают суммарный сдвиг `+4`);
   - ставится **В НАЧАЛЕ страницы**, с которой смещение действует, **перед первым
     заголовком этой страницы** — тогда номера на страницах и в содержании
     совпадают;
   - если вызов окажется в середине страницы, нумерация «рассинхронизируется»
     (заголовки до места вызова сохранят прежние номера в содержании, футер
     покажет уже сдвинутый) — этого нужно избегать;
   - пример: лист рецензии вкладывается отдельно при печати и считается
     страницей — перед началом нумерованных страниц ставят `#page-num-offset(1)`.

## Как реализовано в стиле (из extended.typ)

- Футер работает через `context` и два состояния:
  - `page-num-enabled-state` (default `true`) — включается/выключается командами
    `#page-num-on()` / `#page-num-off()`;
  - `no-num-page-state` (default `none`) — номер страницы, на которой номер скрыт
    (`#no-page-num-start()` запоминает `here().page()`).
  - Номер печатается, только если нумерация включена И текущая страница не равна
    подавленной.
- Номер — **правый нижний угол**, кегль **12pt**, **приподнят на 1 см от нижней
  кромки** листа (`pad(bottom: 1cm)`), в пределах нижнего поля 2 см (по ГОСТ номер
  не прижат к обрезу листа).
- `#page-num-offset(n)` реализован через счётчик страниц:
  `counter(page).update(counter(page).get().first() + n)` — поэтому содержание
  (`#outline`, читает тот же счётчик) остаётся согласованным.
- `#no-page-num-end()` — пустой блок-маркер (`[]`), сам номер не подавляет; нужен
  только для читаемости границ блока.

## Запреты

- В лабораторной работе НЕ включать нумерацию: не ставить `#page-num-on()`
  и не использовать `#no-page-num-start()` / `#no-page-num-end()`.
- В ПЗ не менять порядок `start → блок → end`.
- Не ставить `#page-num-offset(n)` в середине страницы после уже напечатанных
  заголовков.
