# Экранирование специальных символов

Блок: вывод символов разметки Typst как есть, а также корректное использование
тильды.

## Правила

### Экранирование символов разметки

Символы разметки Typst (`@`, `#`, `\`, `$`, `{`, `}`) для вывода как есть
экранируются обратным слешем:

| Символ | Запись в Typst | Назначение |
|---|---|---|
| `@` | `\@` | литеральный @ (например, в e-mail) |
| `#` | `\#` | знак номера |
| `\` | `\\` | обратная косая черта |
| `$` | `\$` | знак доллара |
| `{` | `\{` | открывающая фигурная скобка |
| `}` | `\}` | закрывающая фигурная скобка |

### Тильда

- Одиночная тильда `~` в тексте — это **неразрывный пробел**, а не знак
  «приблизительно».
- Нельзя писать «примерно 60000» через `~60000` — тильда исчезнет из печати.
- Для «приблизительно» используй `≈` или слово, например «примерно 60000».

## Запреты

- Не использовать `~` перед числами для обозначения приблизительности.
- Не забывать экранировать `#` и `$`, если они нужны как печатные знаки.
