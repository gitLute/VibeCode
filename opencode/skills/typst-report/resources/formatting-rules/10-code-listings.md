# Листинги кода

Блоки: блоки кода/текста в отчёте и приложениях. Три способа: фенс-блок, `#raw`,
`#raw(read(...))`.

## Синтаксис

### 1. Фенс-блок (канонический способ)

```typ
\   // пробельная строка перед листингом
```txt
[environment]
test_mode = true
data_path = ./datasets/z1.csv
```
\   // после листинга
```

Указание языка: ` ```txt`, ` ```sql`, ` ```python` — включается **подсветка
синтаксиса**.

### 2. Функция `#raw("...")`

```typ
#raw("SELECT 1;")              // inline внутри абзаца (одна строка без переноса)
#raw("...", lang: "sql")       // блок с подсветкой по lang
```

- Строка **без переноса** рендерится INLINE внутри абзаца.
- Многострочная строка (управляющий `\n` или переносы в исходнике) — блоком.

### 3. Вставка целого файла

```typ
#raw(read("report_code/01.sql"))
```

- `read()` читает файл целиком как текст, `raw()` выводит его как листинг.

## Правила

1. Канонический способ листинга — **фенс-блок**; при указании языка подсветка
   синтаксиса включается автоматически.
2. **Пробельные строки обязательны перед и после листинга** («при листинге
   кода/текста и изображений должны присутствовать пробельные строки перед
   и после листинга»).
3. В `#raw("...")` **без явного языка подсветка отсутствует** (текст чёрный).
   Подсветку даёт только `lang:`.
4. Для больших приложений со скриптами удобен `#raw(read("..."))` — содержимое
   внешнего файла вставляется целиком.
5. Гарантию чёрного текста листингов даёт дополнительная правка в преамбуле:
   ```typ
   #show raw.line: it => {
     set text(fill: black)
     it
   }
   ```
6. Между описанием и кодом в приложении — пробельная строка.

### В приложениях

7. В приложениях так же работают `#raw("...")` и `#raw(read("..."))`.

### Из стиля (extended.typ)

- Стиль сбрасывает для листингов абзацный отступ (1.25 см) и выравнивание по
  ширине: содержимое `#raw` и фенс-блоков выравнивается по ЛЕВОМУ краю страницы.
  Фенс-блоки (блочный raw) оборачиваются в `block`, многострочные
  `#raw("...")`/`#raw(read(...))` — в `par(first-line-indent: 0pt, justify: false)`;
  inline `#raw("...")` внутри абзаца стиль не трогает.
- Размер шрифта листингов (11.3pt = 0.8em — дефолт Typst), чёрный текст и подсветка
  по `lang` обеспечиваются дефолтом Typst и правкой `#show raw.line`.
- Глобальное правило «латиница курсивом» на листинги не распространяется (raw —
  не текст), оформлять код вручную курсивом не нужно.

## Запреты

- Не использовать фенс-блок без языка, когда нужна подсветка.
- Не пропускать пробельные строки вокруг листинга.
- Не вставлять содержимое длинных файлов копированием — используй
  `#raw(read("..."))`.
