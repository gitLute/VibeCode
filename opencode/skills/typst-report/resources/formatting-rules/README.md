# Правила оформления отчётов в Typst

Файлы этого каталога — **источник истины по оформлению** отчётов. `README.md`
(этот файл) читается **обязательно** перед генерацией или изменением любого
отчёта; файлы `01`-`14` читаются по блокам, согласно карте ниже.

Правила извлечены из двух эталонов (стиль у обоих один — `styles.extended`
пакета Ghost):

| Тип работы | Эталон | Титул | Файлы правил |
|---|---|---|---|
| Лабораторная, расчётная (отчёт) | `resources/lab-style/` | `pages.title` | все файлы, акцент — `06` |
| Пояснительная записка (ПЗ) | `resources/curse-style/` | `pages.curse-title` | `14-pz.md` + общие |

Общие (действуют в обоих): `01`-`05`, `07`-`13`. Ветка ПЗ: `14` — структура,
заголовки-уровни, содержание, список источников, требования 8/9/18.

## Статус эталонов

Эталоны перерабатываются в **реальные реализации работ, проверенные
преподавателем**, и могут быть временно неверны или некомпилируемы. При
расхождении эталона с этими правилами следуй правилам данного каталога и
сообщи пользователю о расхождении.

## Структура отчёта (порядок блоков в эталоне лабораторной работы)

1. Преамбула: импорт Ghost, `#show: styles.extended`; для лабораторной —
   `#page-num-off()` (нумерация страниц не требуется)
2. Титульный лист (в лабораторной работе нумерация страниц не требуется)
3. Переопределение стиля листингов (чёрный текст)
4. `*Цель работы:*` + текст
5. `*Задание:*` + нумерованный список
6. Разделы выделенным текстом: `*Теоретические сведения*`, `*Ход выполнения работы*`
7. Таблицы, рисунки, листинги внутри разделов
8. `*Вывод:*`
9. `#pagebreak()` + приложения через `#appendix`
10. В приложениях — таблицы и рисунки; буква приложения определяется
    автоматически (`#appendix` публикует её в `state("appendix")`)

## Структура ПЗ (порядок блоков в эталоне пояснительной записки)

1. Импорт Ghost, `#show: styles.extended`
2. Титульный лист `pages.curse-title` (без номера)
3. `#outline` — СОДЕРЖАНИЕ (номер на первой странице подавлен)
4. `#heading(level: 1, numbering: none)[Введение]`
5. Разделы `=` (подразделы `==`, пункты `===`)
6. `#heading(level: 1, numbering: none)[Заключение]`
7. `#heading(level: 1, numbering: none)[Список использованных источников]`
8. `#pagebreak()` + приложения через `#appendix`
9. В приложениях — таблицы и рисунки; буква приложения определяется
   автоматически (`#appendix` публикует её в `state("appendix")`)

Отличия от лабораторной работы: настоящие заголовки-уровни (а не выделенный текст),
секционная нумерация объектов («Таблица 2.1», «Рисунок 2.1»), обязательные
Содержание и Список источников.

## Принципы работы стиля (из кода `styles/extended.typ`)

`styles.extended` — локальное дополнение пакета Ghost
(`~/.local/share/typst/packages/mih4n/ghost/1.0.1/styles/extended.typ`). Ключевые
механизмы, которые важно знать при написании отчёта:

- **Базовые установки** (задаёт стиль, в отчёте не повторяются): Times New Roman 14pt,
  язык ru, переносы слов ОТКЛЮЧЕНЫ (`hyphenate: false`); страница A4, поля 3/1/2/2 см
  (левое 3, правое 1, верхнее 2, нижнее 2); выравнивание по ширине
  (`justify: true`), межстрочный интервал и меж абзацев — 0.5em; абзацный отступ
  1.25 см для ВСЕХ абзацев.
- **Все заголовки — 14pt**: стиль сбрасывает дефолтное масштабирование Typst
  (`show heading: set text(size: 14pt)`), чтобы разделы/подразделы/пункты не
  «раздувались».
- **Многострочные заголовки** выравниваются по первой букве первой строки
  (hanging-indent по ширине номера), переносы в заголовках запрещены.
- **Регистры**: `fix-case` — наименования строчными с первой прописной (одиночные
  буквы, в т.ч. «А», «Б», не изменяются; сплошные ПРОПИСНЫЕ слова приводятся
  к строчным); `structural-case` — «введение/заключение/содержание» ПРОПИСНЫМИ,
  остальные структурные части — `fix-case`.
- **Пункты (уровень 3)** — без заголовка, как обычный абзац: номер курсивом,
  текст обычным, после номера отступ 0.6em, в содержание НЕ входят.
- **Списки**: перечисления `+` — `set enum(full: true, numbering: "1.1.")`
  (сквозная вложенная нумерация «1.», «1.1.»); маркированные `-` — собственный
  рендеринг маркеров по глубине вложенности; `set list(indent: 1.25cm)`.
- **Счётчики объектов**: `counter("sec")` хранит текущий раздел; при заголовке
  раздела уровня 1 счётчики `fig`/`tab` сбрасываются (нумерация в пределах раздела
  «Рисунок 3.4»); если разделов нет (`sec == 0`) — сквозная «Рисунок 1»; в приложении
  сбрасываются счётчики `fig-<буква>`/`tab-<буква>` («Рисунок Б.1»).
- **Буква приложения**: `#appendix` публикует её в `state("appendix")`;
  блоки `#picture`/`#table-block` читают её и нумеруют объекты приложения
  автоматически («Рисунок Б.1», «Таблица Б.1») — ручной `part` в приложении
  не нужен.
- **Латиница**: все латинские буквы автоматически курсивом по всему тексту
  (`show regex("[a-zA-Z]"): set text(style: "italic")`) — вручную курсив не ставится.
- **Таблицы**: текст 12pt, шапка (строка `y: 0`) полужирная автоматически.
- **Листинги**: стиль сбрасывает для `#raw` и фенс-блоков абзацный отступ 1.25 см
  и выравнивание по ширине (`justify`) — код выравнивается по левому краю страницы.
  Фенс-блоки — через `block`, многострочные `#raw("...")`/`#raw(read(...))` — через
  `par(first-line-indent: 0pt, justify: false)`; inline `#raw` остаётся как есть.
- **Оглавление**: номера страниц — в колонке у правого края, выровнены ПО ЛЕВОМУ
  краю (белая подложка под номером закрывает точки лидера); подразделы смещены
  на 1.25 см; регистр записей — `fix-case`.
- **Нумерация страниц**: футер через два состояния — включена ли нумерация и на какой
  странице номер подавлен; номер приподнят на 1 см от нижней кромки листа (в пределах
  нижнего поля 2 см), кегль 12pt. В лабораторной работе нумерация страниц **не
  требуется**: её отключают `#page-num-off()` (см. `13-page-numbers.md`); всё
  перечисленное действует при включённой нумерации (ПЗ).

## Общие принципы (применимы ко всем блокам)

- Пробельная строка `\` ставится **между отличающимися блоками текста** и **перед/после**
  таблиц, рисунков и листингов. Исключение: после заголовков уровней 1-2 пробельную
  строку НЕ ставят — её добавляет стиль автоматически.
- На все таблицы и рисунки **обязательны ссылки в тексте**.
- Нумерация рисунков и таблиц: сквозная («Рисунок 1», «Таблица 1») при отсутствии
  заголовков-разделов; в приложениях — по букве приложения («Рисунок А.1», «Таблица Б.1»).
- Заголовки разделов в лабораторной работе — **выделенный текст** `*...*`, без номеров
  и без заголовков-уровней Typst.
