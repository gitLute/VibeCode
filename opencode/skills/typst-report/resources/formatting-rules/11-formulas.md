# Формулы

Блок: математические выражения внутри текста или отдельной строкой.
В Typst формулы записываются между знаками `$...$`.

## Синтаксис

```typ
Например, быстрая сортировка имеет среднюю сложность $O(n log n)$, что делает её
одной из самых популярных на практике.
```

## Правила

1. Формула заключается в `$...$` (инлайн в строке текста).
2. Латинские обозначения в формулах — курсивом (обеспечивает стиль).
3. К требованиям ГОСТ к тексту (запрет на «минус» знаком, знаки «номер»/«процент»
   без чисел и т. п.) формулы **не относятся** — они исключены из текстовых
   ограничений наряду с таблицами и рисунками.

## Как оформляет стиль (из extended.typ)

- Латинские обозначения в формулах (и вообще в документе) автоматически курсивом:
  глобальное правило `show regex("[a-zA-Z]"): set text(style: "italic")`. Вручную
  курсив для латинских букв не ставится.
- Кегль формул — базовый 14pt текста.

## Запреты

- Не забывать закрывающий `$`.
- Не использовать `~` для «приблизительно» внутри формулы — там `~` это пробел;
  для знака «приблизительно» пиши `≈`.
