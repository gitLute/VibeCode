# Списки

Блоки: нумерованные перечисления и маркированные списки, в том числе в «Задании».

## Синтаксис

```typ
// Нумерованный список — знак +
+ Изучить типовые алгоритмы обработки одномерных массивов;
+ Разработать алгоритмы, программы и тесты ...;
+ Сравнить производительность различных алгоритмов сортировки.

// Ненумерованный список — знак -
- первый пункт
- второй пункт
```

## Правила

1. Для нумерованных списков используется знак **`+`**, для ненумерованных — знак **`-`**.
2. В «Задании» разрешается использовать нумерованный список **или таблицу**.
3. Список отделяется от предыдущего и последующего текста пробельными строками.
4. Стиль `styles.extended` оформляет списки по ГОСТ автоматически: маркеры по
   уровням вложенности, нумерация сквозная вложенная («1.», «1.1.»), текст 14pt.
   Вручную нумерацию и отступы задавать не нужно.

## Как стиль оформляет списки (из extended.typ)

- `set enum(full: true, numbering: "1.1.")`: нумерованные перечисления `+` получают
  **сквозную вложенную нумерацию** — на первом уровне «1.», «2.»; на вложенном —
  «1.1.», «1.2.» (путь уровней отслеживается состоянием `enum-path`).
- `set list(indent: 1.25cm)`: маркированные списки `-` рендерятся собственным
  show-правилом: маркер печатается по уровне вложенности (если маркер задан массивом —
  циклично по уровням), текст — 14pt, как основной.
- Номер/маркер печатается **с абзацного отступа** (глубина списка × 1.25 см),
  продолжение строк — **по левому краю** страницы.

## Запреты

- Не использовать `+`/`-` с ручной нумерацией или отступами — стиль управляет
  оформлением сам.
- Не вставлять вручную пробельные строки между пунктами одного списка.
